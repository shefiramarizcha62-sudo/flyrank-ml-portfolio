# work/outputs

This directory contains public-safe, aggregate experiment metrics extracted from the saved outputs in `work/notebooks/capstone.ipynb`.

## Files

- `baseline_metrics.json`: rule-based baseline metrics on the client-grouped test split.
- `model_metrics.json`: final capstone Random Forest evaluation, classification metrics, confusion matrix, configuration, and feature importance.
- `validation_metrics.json`: separate W6 comparison between random and client-grouped validation.
- `action_queue_summary.json`: aggregate counts and score distribution for the retrospective ranked action queue.

## Important interpretation notes

- `model_metrics.json` and `validation_metrics.json` document different evaluation runs. Do not treat their grouped-split scores as a single identical run.
- The ranked action queue was generated by fitting the final model on the full March-April labeled dataset. It is a retrospective development artifact, not a prospective end-of-March prediction.
- These files contain aggregate metrics only. Do not commit raw datasets, raw ranked queues, client/content identifiers, private URLs, or credentials.
- Metric values were transcribed from the saved notebook outputs. Re-running the notebook may produce differences if the dataset or software environment changes.
